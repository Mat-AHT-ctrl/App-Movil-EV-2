## Descripcion
App movil en Android (Kotlin + Jetpack Compose) para gestionar la reserva de espacios y archivos del Colegio Marcela Paz.

## Funcionalidades principales
* Reservar espacios (salones, laboratorios, biblioteca)
* Ver y cancelar mis reservas
- Subir archivos (PDF, Word, fotos)
- Aprobar o rechazar solicitudes (admin)
